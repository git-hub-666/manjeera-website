Products

IP, silicon and systems.

A portfolio spanning FPGA implementation, silicon-verified ASIC IP and the DB-01 system-on-chip.

UMA IP / FPGA

High-performance FPGA implementation

The official product material describes UMA IP for standalone systems or as an accelerator connected to a host through a high-speed link such as PCIe.

  • Turnkey FPGA implementation of UMA IP-based solutions
  • Customer-specific implementations
  • Support for multiple FPGA families including Intel and Xilinx
  • Quick prototyping
UMA IP / ASIC

Silicon-verified accelerator IP

UMA IP for ASIC integration, with a published scalable architecture intended to cover both low-power and high-performance requirements.

  • Silicon-verified UMA IP
  • Vector length 4–16
  • 1–32 cores
  • Local memory up to 256KB
  • Custom instructions
