Technology / UMA

UMA is the computing architecture.

Universal Multifunction Accelerator (UMA) is Manjeera’s hardware IP architecture based on Middle Stratum Operations (MSO), designed around programmability, parallel computation and local-memory execution.

ARCHITECTURE

Middle Stratum Operations.

The public technical material describes MSO as a computational approach between conventional instruction-level execution and specialized fixed-function acceleration.

Algorithms

ML / DL · CNN / RNN · computer vision · image processing · signal processing.

MSO

Parallel configurable computation

MSOs are configurable on the fly; computations are performed using local memory and programmed through standard load/store instructions.

Integration

Standard processor/system interfaces; designed for FPGA implementations and ASIC integration.
